# Santuario VR — un file, un link, un visore

Niente store. Niente account Meta per entrare.
Un file HTML. WebXR. Browser del Quest.

Repo: https://github.com/raffaellocantatelli/santuario-vr

## Cosa è

Crepuscolo. Otto colonne che non reggono un tetto.
Un libro di pietra che non si legge.
Una candela che si accende solo se tieni premuto **12 secondi**.

Se la tesi del «già» fosse falsa, il gesto resterebbe lo stesso.

## Aprirlo adesso (senza visore)

Apri `index.html` in Chrome o Edge.
Click per guardare. WASD per camminare.
Click tenuto sulla candela.

## Aprirlo negli occhiali (Quest 2 / 3 / 3S)

WebXR vuole **HTTPS**.

1. GitHub → repo → Settings → Pages → Source: GitHub Actions (o Deploy from branch `main` / root).
2. URL atteso: `https://raffaellocantatelli.github.io/santuario-vr/`
3. Nel browser **del Quest** apri quell’URL.
4. Premi **Enter VR**.
5. Punta il raggio sulla candela e tieni il grilletto dodici secondi.
